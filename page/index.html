YouTrack from the terminal

ytrack

A small cross-platform CLI for creating YouTrack issues, moving their status, and keeping global credentials separate from per-project config.

Download View Source 
ytrack global set-url https://youtrack.example.com
ytrack global set-token perm:your-token
ytrack set-project-id 0-1

ytrack issue create "Crash on save" "Steps to reproduce"
ytrack issue status ART-123 Done

Install a release binary

Grab the package for your platform from GitHub Releases. Each release includes Linux, macOS, and Windows builds plus SHA-256 checksums.

macOS

Download the Darwin archive for Intel or Apple silicon.

Linux

Use the AMD64 or ARM64 archive and place the binary on your PATH.

Windows

Download the ZIP package and run ytrack.exe.

Config that follows your work

Store the YouTrack URL and token globally, then keep the project ID inside each repository's local .ytrack/config.json.

Layered config

Local values override global values, while project_id stays local-only to avoid creating issues in the wrong project. 

ytrack show
ytrack --json issue create "Add release docs"
ytrack issue status ART-123 In Progress
